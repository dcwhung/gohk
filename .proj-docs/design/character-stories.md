# 四個主角嘅單人故事（草案 v1）

> 2026-10-15 grill-me 輸出。原則：四個角色係一家人，各自有「今日要趕去邊」嘅理由；單人模式每個角色玩同一套 5 關地圖，但開場、每關理由、對白、結局唔同。最後全部收返喺獅子山下彩虹邨嘅家食飯——「平時一家人一齊嘅時間都好難得，珍惜倒數緊嘅人生」（彩虹邨清拆倒數 = 人生倒數，雙關）。
>
> 關卡次序（已定）：1 旺角街市 → 2 尖沙咀・小輪 → 3 中環・電車 → 4 山頂・獅子山 → 5 黃大仙・彩虹邨。
> 每關有一個「故事主人」（storyOwnerId）：1 外賣仔、2 學生、3 打工仔、4 全家會合（無主人）、5 老人家。雙人 / 合併方式之後再定。

## 1. 外賣仔 ——《一單外賣，改咗五次地址》

**開場**：旺角茶餐廳，落雨。阿姐掟張單俾佢：「上寫字樓，快手」。單上寫住一個電話，冇名。
**驅動力**：客人每次就送到就改地址，仲要係「我喺尖沙咀……唔係，過咗海……」。外賣仔由步兵變單車變電單車，追住個客人全港走。

| 關              | 外賣仔喺度做乜                                                       | 專屬互動                                         |
| --------------- | -------------------------------------------------------------------- | ------------------------------------------------ |
| 1 旺角          | 由茶餐廳出發，街市人多路窄，譚仔阿姐迫佢「食碗先走」                 | 落單暗語 mini-game 係佢嘅教學關；boss 後攞到單車 |
| 2 尖沙咀        | 客人話「喺鐘樓」，到咗又話「上咗小輪」；追上小輪                     | 小輪甲板平衡托盤；澳牛阿哥催佢「唔食就走」       |
| 3 中環          | 客人話「喺寫字樓 38 樓」，保安唔俾上，爬後樓梯                       | 升降機機關；的士狗唔肯載佢上山頂 → 攞到電單車    |
| 4 山頂→獅子山   | 客人話「落咗山返九龍」，紅 Van 超速追逐                              | 電單車 vs 火箭紅 Van 追逐段                      |
| 5 黃大仙→彩虹邨 | 最後地址係自己屋企。原來係阿婆訂嘅——「叫你返嚟食飯啫，唔係咁你唔返」 | 清拆巨槌 boss；結局全家食飯                      |

**結局語**：「送咗成日，原來係送返自己屋企。」
**武器 / 技能**：鐵食物盤（近戰）、菠蘿包→雞尾包→蛋撻三連掟、形態切換（步行 / 單車 / 電單車）。

## 2. 打工仔 ——《今晚趕埋佢》

**開場**：中環寫字樓，21:30。老細：「份 proposal 今晚要客簽名，佢而家喺旺角食嘢，你去追。」HR 同時 send 咗封「架構重組」email。
**驅動力**：追老細簽名。老細一邊去食飯、返山頂屋企，一邊 WhatsApp 叫改嘢：「個 logo 大啲」「唔好，細返」「用藍色」「都係紅色好啲」……改咗五次，最後簽嘅係第一個版本。期間炒股 / 開 live 補貼家用。
**核心機制「改完又改」**：每關老細發一個新要求（關卡目標微變，例如要多攞一樣嘢先過關），第 5 關老細話「都係第一版啦」——所有改動歸零，玩家攞返第 1 關嘅文件即可過關。

| 關               | 打工仔喺度做乜                                                             | 專屬互動                                                 |
| ---------------- | -------------------------------------------------------------------------- | -------------------------------------------------------- |
| 1 旺角           | 追客去譚仔，客人食緊米線唔簽                                               | 「坐艇」技能首次教學；街市股票 App 紅綠燈 HUD            |
| 2 尖沙咀         | 客人上咗小輪去會展開會                                                     | 小輪上開 live 賺 like；澳牛阿哥鬧佢「返工時間玩 IG」     |
| 3 中環（主人關） | 返到公司，老細話文件要送上山頂屋企；OT 地獄：每打一個敵人多一份工          | boss 的士狗（唔過海→變飛的士）；「老細永遠喺你後面」機制 |
| 4 山頂→獅子山    | 送到山頂，老細睇完話「都係第一版好啲」，但第一版留咗喺旺角                 | 「輸到趴街」狂暴狀態；紅 Van 落山                        |
| 5 黃大仙→彩虹邨  | 阿媽電話：「返嚟食飯」。第一版原來一直喺公事包底，一早簽得。第一次準時收工 | 清拆巨槌；結局語                                         |

**結局語**：「改咗成日，最後都係第一版。份工趕唔切，但飯一定要食。」
**武器 / 技能**：公事包（近戰）、文件夾 / 名片掟、炒股（賭金幣）、KOL 開 live（嘲諷 + like 回血）。男女 skin 數值技能一樣。

## 3. 學生 ——《五個興趣班》

**開場**：06:00 彩虹邨，虎媽貼咗張時間表喺雪櫃：旺角奧數 → 尖沙咀英文 → 中環鋼琴 → 山頂面試班 → 黃大仙珠心算。「唔准遲到，隔籬屋個仔已經去咗。」
**驅動力**：趕足五個班，每個班門口都有一個「隔籬屋個仔」（鏡像敵人）快佢一步。

| 關                 | 學生喺度做乜                                                       | 專屬互動                              |
| ------------------ | ------------------------------------------------------------------ | ------------------------------------- |
| 1 旺角             | 奧數班喺街市樓上，書包太重行唔郁                                   | 「減負」丟書機制；士多扭蛋 / 閃卡引誘 |
| 2 尖沙咀（主人關） | 補習社燈箱海報，補習天王從海報跳出                                 | mini-boss 補習天王；過海去中環鋼琴班  |
| 3 中環             | 鋼琴班，「鋼琴八級」音波技能教學                                   | 電車上做功課                          |
| 4 山頂→獅子山      | 面試班：「請自我介紹」洗腦攻擊                                     | 「扮病請假」隱身逃走                  |
| 5 黃大仙→彩虹邨    | 珠心算班完，仲有三份功課未做，趕返屋企做功課；返到門口全家已經喺度 | 清拆巨槌；結局語                      |

**結局語**：「功課做唔晒，但飯要一齊食。」
**武器 / 技能**：書包（近戰 / 盾）、補習筆記 / 水樽掟、「開竅」攻速 buff、「死記硬背」複製敵人招式。

## 4. 老人家 ——《排籌》

**開場**：05:30 黃大仙祠，阿婆上頭炷香，求咗支籤：「家宅：宜聚」。之後去聖母醫院排籌，籌號 9527，而家叫緊 12。
**驅動力**：等籌期間決定「叫全家返嚟食餐飯」，兩蚊車走勻全港搵每個人（佢唔識用 WhatsApp，要親自去）。最後揀咗用外賣仔間茶餐廳落單，地址一路跟住自己走——呢個就係「神秘客人」。

| 關                        | 老人家喺度做乜                                       | 專屬互動                                              |
| ------------------------- | ---------------------------------------------------- | ----------------------------------------------------- |
| 1 旺角                    | 去茶餐廳落單叫外賣（「送去……我諗吓先」），街市買餸   | 講價 mini-game；關愛座首次教學（巴士）                |
| 2 尖沙咀                  | 去補習社搵細佬，補習社話佢過咗海                     | 小輪長者免費；澳牛阿哥見到阿婆即刻有禮貌（彩蛋）      |
| 3 中環                    | 上寫字樓搵阿仔，保安「登記身份證」                   | 唔識用電子支付；八達通「請再試一次」                  |
| 4 山頂→獅子山             | 搭山頂纜車，落山搭紅 Van 返九龍                      | 紅 Van 司機見到阿婆減速（彩蛋：「阿婆你坐穩」）       |
| 5 黃大仙→彩虹邨（主人關） | 返醫院，籌號啱啱叫到；睇完醫生返屋企，全家已經喺門口 | 清拆巨槌 boss：阿婆用「當年……」講古令巨槌瞌眼瞓；結局 |

**結局語**：「幢樓就快拆，人就快走，所以今晚一定要齊人。」
**武器 / 技能**：拐杖 / 購物車仔（近戰）、保溫壺 / 涼茶 / 紙皮掟、「長者優先」（兩蚊車 + 關愛座盾 + 排籌回血）、「當年……」（講古令敵人瞌眼瞓）。

## 共同結局（四條線都收喺度）

彩虹邨某單位，窗口望到獅子山。枱上係外賣仔送到嘅外賣、阿婆買嘅餸、細佬偷偷買嘅砵仔糕、阿爸喺便利店買嘅啤酒。窗外圍板寫住「清拆倒數 365 日」。

畫面切去 16-bit：同一個單位，1990 年代，同一家人細個嗰陣食飯。再切返平滑：而家。字幕：「珍惜倒數緊嘅人生。」
