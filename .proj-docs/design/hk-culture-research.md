# 香港文化 Research：近 20 年有趣事件 × 遊戲化素材

> 2026-10-15 由三個 research agent（潮語 / 社會事件 / 小人物日常）整合。用途：對白、道具、敵人、技能、random event 嘅素材庫。每條都附「風險」欄，設計時按 game-design.md §13 尺度（粗口諧音遮掩、品牌改名、純政治避開）取用。
>
> 用戶指定必入元素：譚仔話、反智轉身、你個嘢壞咗、SARS、雷曼、八萬五、關愛座、排隊睇醫生、搭棚、盂蘭勝會、舞龍舞獅。

### 核心梗 Top 10

1. 茶餐廳暗語落單 mini-game（可做核心節奏系統）
2. 巴士阿叔 Boss「你有壓力我有壓力」「未解決！」

4. 的士「唔過海」「交更」攔車 running gag
5. 「食花生」隱身道具
6. 「派膠 / 賜酒」評價貨幣貫穿 UI
7. 「少癲 / 大癲 / 巨癲」難度 + 「sldpk」笑倒狀態
8. 「來都來了」強行入關 + 「贏咗 99% 香港人」彈窗
9. 「雞，全部都係雞」隱藏雞場關
10. 「係愛呀」萬用解釋 + 「你係咪嬲咗我」伙伴系統
