# 外賣仔 — 玩法設計（Gameplay Spec v0.1）

> 2026-10-15 用戶口述，逐條 grill 中。呢份文件係外賣仔嘅「玩法」；「故事」喺 character-stories.md §1。
> 原則：一個角色定晒先去下一個，唔做到不倫不類。

## 背景

讀書唔叻，乖乖仔，為咗頭家好努力透過外賣平台接單送外賣賺錢，實現自己嘅夢想。

## 關卡結構

- 每關由 **2–3 個場景（scene）+ 1 個 boss 場景** 組成。
- 每個場景係一條街：橫向移動，背景係一間間舖頭 / 餐廳。
- 舖頭會 **隨機** 顯示「有單」/「冇單」。
- 外賣仔經過 / 跳過去有單嘅舖頭，店員 NPC 走出嚟俾單（= Metal Slug 被綁人質）。
- 單有好有差（待定義）。
- 行到場景尾 = 送餐點：有單在手 = 送餐成功；冇單但仲有命 = 食白果 / 白做。
- 最尾場景係 boss：第 1 關譚仔阿姐、第 2 關澳牛粗口侍應；其餘 boss 同擊敗方法未定。

## 過關 / 計分

- 過關條件：準時送單 + 餐齊（嘢食 + 餐具）。
- 接到一張單就有一定分數。

## 生命 / 信譽

- 3 條命（準時度）。
- 另有信譽度。
- 遲到被投訴 → 扣信譽度。
- 被敵人掂到 → 扣一條命，同時彈晒手上嘅單出嚟；啲單幾秒後消失，玩家可以喺呢幾秒執返（超音鼠金環機制）。

## 敵人

- 其他 NPC 外賣仔（步兵 / 騎兵）會搶單：只搶主角手上嘅單，唔搶舖頭嘅單。
- 擊中敵人 → 敵人消失或逃跑。

## 攻擊

| 距離 | 方法                                      |
| ---- | ----------------------------------------- |
| 近   | 用保溫箱打走敵人                          |
| 遠   | 掉外賣餐具                                |
| 載具 | 單車 / 電單車撞敵人；撞到會跌出啲單可以執 |

## 道具

餐具 / 飯盒、保溫箱、單車、電單車。

## 外賣仔移動形態

每關開始都係步兵（行 / 跑），之後可以攞到單車 / 電單車。
