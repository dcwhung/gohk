# 外賣仔線 — 完整 Game Flow Walkthrough（v1 草案，2026-10-16）

> 用途：由開機到結局行一次，砌晒故事 + 玩法，搵唔合理同缺口。玩法規則見 gameplay-delivery-boy.md；呢份係「玩家會經歷嘅次序」。
> 季節：農曆七月。一日時間線：朝早 → 深夜。

| 步驟 | 畫面       | 內容                                                                                                                       |
| ---- | ---------- | -------------------------------------------------------------------------------------------------------------------------- |
| 0.1  | Title      | 遊戲名（未定）、「撳任何掣開始」、背景：等角浮島香港夜景，招牌閃                                                           |
| 0.2  | 選角       | 四格：外賣仔（可揀）、打工仔 / 學生 / 老人家（「整緊，等陣先」）。揀外賣仔 → 一句自我介紹：「讀書唔叻啫，送外賣我叻。」    |
| 0.3  | Overworld  | 等角香港地圖，6 個節點（旺角 → 尖沙咀 → 中環 → 銅鑼灣 → 荃灣 → 彩虹邨），外賣仔 icon 喺旺角。第一次只有節點 1 亮。撳入關。 |

## 1. 第 1 關 旺角 → 油麻地 → 佐敦（接單・早餐）

**開場一句**（app 叮一聲）：「新單：佐敦澳牛早餐 ×1。順便接埋沿途嘅單啦。」

| 場景                  | 畫面 / 流程                                                | 雜兵                                                                                                                             | 機制 / 教學                                                                                                                                                |
| --------------------- | ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1.1 旺角街市 + 女人街 | 街市濕地、魚檔、紅燈罩；街市大廈樓上酒樓外牆，點心車推出嚟 | **街市阿嬸**（推車仔橫行，撞到彈單）；**點心車阿姐**（車係移動平台，跳上去俾一張單，被車撞彈單）；**鴿子**（俯衝，屙屎落地變滑） | 教學：方向鍵行、Z 跳、上+X 接第一張單（店員舉單）、X 近戰打阿嬸、C 掟餐具（地上執）。第一間士多（教買嘢）。場景尾送餐點                                    |
| 1.2 油麻地信和 / 果欄 | 信和招牌、果欄紙皮箱堆                                     | **送貨佬**（推手推車直線衝，掟橙拋物線）；**搶單外賣仔（步兵）**（撞到跌晒單唔扣命，然後反方向跑）                               | 教學：被撞跌單 → 幾秒內執返。第一個懷舊食物（砵仔糕）→ 切 16-bit 20 秒：果欄變 60 年代，舊舖單貼士高                                                       |
| 1.3 佐敦澳牛門口      | 澳牛招牌、玻璃門、阿哥企喺門口                             | **Boss 澳牛粗口哥**（見 gameplay §Boss）                                                                                         | Boss 開場：「我哋唔做外賣㗎！■快啲走！」玩家用保溫箱擋佢掟嘅餐 = 接到單。半血 → 奶茶杯飛船 + 乳牛。打贏：阿哥：「……食唔切就走。」Boss 單「澳牛早餐」入 HUD |

**過關結算**：隨機單數 / 準時數 / 貼士 / 信譽變化。**解鎖單車**（過場：街坊阿叔「架單車擺喺度冇人要，你攞去啦」）。

## 2. 第 2 關 尖沙咀 → 小輪 → 中環（送餐・俾阿爸）

**開場一句**：「送去中環 XX 大廈 38 樓，收件人：陳先生。」（外賣仔唔知係阿爸）

| 場景                          | 畫面 / 流程                                                      | 雜兵                                                                                            | 機制                                                                                                                                        |
| ----------------------------- | ---------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 2.1 尖沙咀街景 → 碼頭         | 太空館蛋形、文化中心斜頂、鐘樓；開場有停車位（單車）             | **打卡遊客**（舉手機閃光致盲 1 秒）；**行李篋旅客**（篋碌過嚟絆腳）；**搶單騎兵**（單車版，快） | 單車首次使用；到碼頭自動落車（單車停碼頭）                                                                                                  |
| 2.2 小輪甲板                  | 背景維港自動捲動，船搖（平台微傾斜，影響單嘅平衡：傾斜時跑會慢） | **跳船搶單外賣仔**（由另一邊船跳過嚟）；**海鷗**                                                | 新武器：救生圈（掟，彈返）。到中環落船                                                                                                      |
| 2.3 中環甲級寫字樓 lift lobby | 大理石地、三部升降機、保安枱                                     | **Boss 看更阿伯**（登記戰）                                                                     | 開場：「登記先！冇登記唔俾上！」打爆 3 個鎖 → 入升降機。過場：38 樓茶水間，阿爸背住鏡頭接過早餐，轉身：「阿仔？！……唔好同阿媽講我食外賣。」 |

**結算**。冇新載具。

**開場一句**：「新單：銅鑼灣譚仔米線 ×1。」時段 12:00。

| ------------------------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 3.1 中環 → 灣仔電車路軌   | 中環舊街、石板街；電車路軌喺畫面中層 | **電車叮叮**（hazard：由畫面邊入，叮叮聲預警，撞到扣命 + 冇晒單）；**低頭族 OL**（行住撞你）；**搶單騎兵** | 跳避電車                                                                                                                                        |
| 3.2 灣仔 → 銅鑼灣電車路軌 | 背景換：藍屋、灣仔街市、修頓球場     | 同上 + **派傳單地產經紀**（傳單黐身減速 2 秒）                                                             | 同 3.1，密度高啲                                                                                                                                |
| 3.3 銅鑼灣圓形天橋底譚仔  | 環形天橋上下層可行；阿姐喺地下門口   | **Boss 譚仔阿姐**                                                                                          | 開場（譚仔話字幕）：「你落錯單啊！十小辣定小小辣？！」掟碗 → 拍返中佢；衝撞後打氣窗口近戰。半血 → 舖頂巨煲機械。打贏：Boss 單「譚仔米線」入 HUD |

**結算**。

## 4. 第 4 關 銅鑼灣 → 灣仔 → 紅隧口 →（過場）荃灣（送餐・俾細佬）

**開場一句**：「送去荃灣 XX 補習社，收件人：陳同學。限時 20 分鐘。」時段 16:30。單倒數特別緊（UI 閃紅）。

| 場景                             | 畫面 / 流程                    | 雜兵                                                               | 機制                                                                                                                                                                                                                        |
| -------------------------------- | ------------------------------ | ------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 4.1 銅鑼灣 → 灣仔街景（單車）    | 放學人潮、校巴                 | **校巴**（hazard）；**購物客**（購物袋橫掃）；**搶單騎兵**         | 單車唔入得隧道：場景尾告示「單車不准進入隧道」→ 外賣仔：「唯有搭的士。」                                                                                                                                                    |
| 4.2 灣仔 → 紅隧口巴士站 / 的士站 | 塞車車龍、巴士站上蓋（可跳上） | **塞車車門**（突然開門撞你）；**巴士站人龍**（障礙）；**搶單步兵** | 排的士                                                                                                                                                                                                                      |
| 4.3 紅隧口的士站                 | 的士狗坐喺駕駛座，車頂燈       | **Boss 的士狗**                                                    | 開場：「汪！唔過海！交更！」橫衝 + 牌 + 尾燈彈幕；爆牌 → 跳上車頂打。半血 → 起飛盤旋。打贏：的士狗耷低耳仔：「……上車啦。」過場：的士過海 → 荃灣補習社門口，細佬接過米線：「阿哥？你送外賣㗎？……唔好話俾阿媽聽我未做功課。」 |

**結算**。**解鎖電單車**（過場：用今日貼士喺荃灣車行買咗架二手電單車，老闆：「後生仔，慢慢揸。」）

## 6. 第 6 關 旺角 → 獅子山下 → 黃大仙 → 彩虹邨（送餐・返屋企）

**開場一句**：「送去彩虹邨 X 樓 XX 室，收件人：陳太。」外賣仔停一停：「……呢個地址。」時段 21:30，夜。

| 場景                                | 畫面 / 流程                                                                  | 雜兵                                                                                           | 機制                                                                            |
| ----------------------------------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 6.1 旺角 → 龍翔道獅子山下（電單車） | 夜路、獅子山剪影、龍翔道天橋                                                 | **夜更貨車**（hazard）；**搶單騎兵（夜間版，車頭燈）**                                         | 電單車高速段；懷舊切換見到 90 年代獅子山下嘅公屋燈火                            |
| 6.2 黃大仙球場盂蘭勝會              | 神功戲棚（多層平台）、燒街衣火堆（陷阱，踩到扣命）、派平安米人龍（移動障礙） | **餓鬼**（半透明，搶你嘅單，怕平安米：拎住平安米佢哋避開）；**戲棚花旦**（唱大戲音波，純干擾） | 道具平安米回命；呢關隨機單少、貼士高（夜深）                                    |
| 6.3 彩虹邨籃球場                    | 七色樓夜景、籃球場、圍板「清拆倒數 365 日」、巨槌                            | **Boss 清拆巨槌**                                                                              | 開場冇對白，只有槌聲。槌落下跳開 → 停頓打關節。純打。打贏：巨槌停低，工人落班。 |

**結局過場**：上樓，門口。阿婆開門：「返咗嚟就食飯啦。」入屋：枱上有外賣仔送到嘅小炒、阿爸食剩嘅澳牛早餐盒、細佬嘅譚仔碗。阿媽：「成日唔返嚟食飯……」外賣仔：「今日送咗成日，原來送返嚟自己屋企。」窗外獅子山。畫面切 16-bit：同一單位 1990 年代同一家人細個食飯。切返現在。字幕：「珍惜倒數緊嘅人生。」Credits。

## Walkthrough 搵到嘅缺口（待 grill）

| #   | 缺口                                                                                         | 建議                                                                                                  |
| --- | -------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| G1  | **Game over 之後點**：命 / 信譽跨關累積，入關時只有 1 條命就死一次 restart 又係 1 條，會卡死 | 「Continue」= 平台罰款：信譽 −20，命回 3 條，由該關場景 1 開始。信譽唔夠 20 就真 game over 返 title。 |
| G2  | **貼士 vs 分數**：貼士係錢（買嘢），分數係排名；兩樣定一樣                                   | 合併：貼士 = 錢 = 分。結算畫面顯示貼士總數。簡單。                                                    |
| G3  | **懷舊模式喺 boss 場景**：可唔可以切                                                         | 唔可以：boss 場景冇懷舊食物 / 電話亭，入 boss 自動切返現代                                            |
| G4  | **Overworld 嘅意義**：6 關線性，地圖只係過場                                                 | 保留做過場 + 存檔點 + 士多（入關前補給）；icon 沿路線移動係一個 5 秒動畫                              |
| G5  | **存檔**：幾時存                                                                             | 每關結算後自動存（關卡進度、命、信譽、貼士、裝備、載具）                                              |
