## 重要決定

| 決定                                        | 原因                                                                  | 影響範圍                      |
| ------------------------------------------- | --------------------------------------------------------------------- | ----------------------------- |
| 引擎用 Phaser 3 + TS + Vite，唔用 Godot     | 用戶係 JS 開發者；網頁版優先；AI 輔助最有效；Steam 日後用 Electron 包 | 整個 codebase                 |
| 關卡間地圖係固定視角等角 2D 插畫            | 用戶參考圖全部係固定視角浮島風格，唔需要 3D                           | OverworldScene、美術 pipeline |

| 切換影響玩法（舊時代 layer / 現代 layer）   | 「懷舊 vs 現代」主題表達                                              | Tiled 雙 layer 設計           |
| 多角色架構，第一版只做外賣仔                | 每角色 = 6 組動畫，先驗證玩法                                         | characters.ts config          |
| 主線：一單超大外賣，客人不斷改地址          | 每關有天然理由                                                        | 劇情、對話                    |
| 粗口諧音遮掩、品牌改名                      | 全年齡、商標風險低                                                    | 對白寫法                      |
| Vite base 用 `mode === 'production'` 判斷   | `command === 'build'` 會令 `vite preview` 載入唔到 JS                 | vite.config.ts                |
